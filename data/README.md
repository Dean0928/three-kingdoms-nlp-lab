# 数据说明

本目录只存放分析所需的原始数据与词表，脚本、Notebook 与输出分别放在 `notebooks/`、`src/` 与 `outputs/`。

| 文件 | 说明 | 来源 |
| --- | --- | --- |
| `raw/sanguoyanyi.txt` | 《三国演义》全文，共 120 回 | 公开的《三国演义》电子文本，作者罗贯中（明代），已进入公有领域，仅供教学与研究使用 |
| `stopwords_cn.txt` | 中文通用停用词表（含标点与符号），约 1700 条 | 常见开源中文停用词表 |
| `lexicons/character_aliases.csv` | 16 位核心人物的人物别名表（长表：标准名, 别名） | 依据原著整理 |
| `lexicons/topic_lexicon.json` | 战争 / 谋略 / 忠义 / 联盟 四个主题的关键词 | 依据原著整理 |

## 语料格式说明

- 文件为 UTF-8 编码，**带 BOM**；
- 开头有卷名、作者与卷首词，属于正文以外的内容；
- 回目标题形如 `第一回  宴桃园豪杰三结义  斩黄巾英雄首立功`，第 41 回使用全角空格；
- 第 40 回结尾混入一处目录式残留 `#第四十一回`，由 `sanguo_nlp.corpus.clean_text` 统一清理。

## 词表维护

- 人物别名表采用长表结构，一行一个别名；同一个标准名可有多行。修改后无需改代码，`load_aliases()` 会自动按“长别名优先”重新编译正则。
- 主题词典为 JSON：主题名 -> 关键词列表。一个关键词可以同时属于多个主题（重叠计数）。
